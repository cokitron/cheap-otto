# Active Lessons — `01-intent-traceability`

- **[L-TR-001]** (`*`) Never allow `Closes #N` or `Fixes #N` in a PR body when acceptance criteria in issue `#N` remain unimplemented; require changing the keyword to `Refs #N` or `Part of #N` so GitHub does not auto-close an incomplete ticket.
- **[L-TR-002]** (`*`) Verify target base branch alignment (`main` vs `development`) against the repository's documented branching workflow.
