Put the dead old MacBook to work.

cheap-otto pairs your Windows workstation with a spare, lid-closed MacBook over SSH so they work like one machine. You get native macOS builds, a farm of coding agents in isolated worktrees, and a PR reviewer that runs overnight. Every change it makes to macOS can be undone with one command.

Guardrailssrc/macos.rs · src/arbiter.rs · everything is snapshotted to .cheap-otto/state-backup.json first

      
A laptop on AC 24/7 needs rules.

      
A fanless MacBook Air with its lid closed, charging all day, is a battery-swell and thermal problem waiting to happen. cheap-otto caps the charge, keeps a battery sleep fallback and evicts local LLM weights before RAM or heat run out. cheap-otto restore puts every setting back.
