Ten checks on the real Mac

Once the dashboard wave was on main, the 10-step rollout in #29 ran against the paired MacBook. Note that code-reviewer m1 and code-reviewer ui act on the Mac immediately, while the cheap-otto commands below wait for --execute:

windows → otto-maclive rollout
# push HEAD, build both binaries on the M1 and install the dashboard LaunchAgents
$ cargo run -p code-reviewer -- m1 sync
# probe launchd and loopback ports on the Mac, plus tunnelled ports here
$ cheap-otto dashboards status --execute
# prove idempotence: a second install prints action=unchanged and keeps every PID
$ cheap-otto dashboards install --execute
# prove KeepAlive: kill Mission Control on the Mac; launchd restarts it within 15s
$ cargo run -p code-reviewer -- m1 exec --cmd 'launchctl kill SIGTERM gui/$(id -u)/com.cheapotto.dashboards.mission-control'
# stop the one tunnel, then bring all three ports back without opening a browser
$ cheap-otto dashboards tunnel --stop --execute
$ cheap-otto ui --execute --no-open

All three services (:7420, :7421, :7430) came up loaded=yes listening=yes behind one ssh process on Windows. Killing Mission Control left the Pixel Office and the Reviewer untouched while launchd restarted Mission Control under a new PID, and ssh otto-mac true ran with zero port-forward warnings.

Scripts go over stdin, not argv

Before #64, dashboards install, uninstall and status packed their whole POSIX script into a quoted /bin/sh -c '<script>' argument (<script> is a placeholder for the rendered script). Now CommandSpec carries an LF-normalised stdin payload and streams multi-line scripts into /bin/sh -s. Here is the real dry run with the default placeholder peer:

What else changed for you

  • Tunnel stop checks when the process was born. tunnel.json now records process_started_at in UTC (Win32_Process.CreationDate on Windows, TZ=UTC LC_ALL=C ps -p <pid> -o lstart= on Unix, where <pid> is a placeholder for the tunnel PID). cheap-otto dashboards tunnel --stop --execute refuses to signal a process unless both its full ssh -N command line and its start time match, and re-checks right before taskkill or kill. Older tunnel.json files without the field still load.
  • Fallback Reviewer tunnels ignore LocalForward in ~/.ssh/config. When code-reviewer ui opens a Reviewer-only fallback tunnel (for a custom --host, a non-7430 --port or an unrecorded peer), it resolves connection settings locally via ssh -G -- <host> (<host> is a placeholder) and spawns ssh -F none with only connection, host-key and agent options plus its single -L forward, so stale config forwards cannot trip ExitOnForwardFailure=yes.
  • Schedule run-now cannot kick a dashboard. POST /api/schedules/<project>/<id>/run-now on Mission Control (<project> and <id> are placeholders) now looks the job up in schedules.json first (404 otherwise), re-runs reject_dashboard_label and verifies the canonical com.cheapotto.<project>.<id> label before calling launchctl kickstart.
  • code-reviewer m1 validates hosts and escapes remote paths. Every m1 SSH call rejects option-like or shell-metacharacter hosts before spawning, ends option parsing with -- before the host, and escapes $ and backticks inside double-quoted remote sh paths.
  • Committed Code Tender KB rules can be edited or deleted in the UI. Editing or deleting a committed rule on :7430 writes an HTML comment tombstone (<!-- otto-kb-deleted: <key> -->, where <key> is a placeholder for the rule text) into ~/.code-reviewer/kb-overrides/ instead of touching git-tracked files. Deleted rules stay gone on reload, in-place edits keep their slot and casing, and a later learned rule revives a tombstoned key cleanly.
  • Agent rules have a byte-cap guard in cargo test. AGENTS.md stays below Antigravity's 24,000-byte inline expansion cap, root .agents/skills.json registers the Reviewer skills, and a test fails if .agents/skills and .claude/skills drift by a byte.
  • Docs and spec PRs clear CI in seconds. PRs touching only specs/, docs/, README.md, CONTRIBUTING.md or LICENSE fast-pass all three required Rust Gate checks on Ubuntu instead of waiting 15 minutes for a queued macos-latest runner, while code PRs route macOS tests onto macos-15-intel (release.yml still builds native aarch64-apple-darwin binaries).

Where review pushed back

Cubic opened 18 review threads across these seven PRs, and Code Tender answered all 18 from the Mac. Three exchanges caught bugs that offline unit tests on the happy path had missed:

  • -F none forgot trust stores (#65). Ignoring ~/.ssh/config dropped LocalForward as intended, and also dropped UserKnownHostsFile, GlobalKnownHostsFile and IdentityAgent. Code Tender added quote-aware ssh -G parsing and -o quoting for paths with spaces.
  • Timezones and 1-second clocks (#66). On Unix, plain ps -o lstart= prints local wall time with no zone, so a DST shift would make a live tunnel fail its own identity check and stay up forever. Code Tender pinned TZ=UTC and LC_ALL=C, and made new tunnel spawns fail closed if the start stamp cannot be read. Cubic also flagged that lstart has 1-second resolution on macOS; getting sub-second birth time there needs libproc (unsafe or a new crate, both against repo rules), while a false match already needs a recycled PID running the identical ssh -N argv within the same second. Code Tender documented that limit and filed #68.
  • Edits in place and --> inside rules (#67). Cubic caught case-only KB edits being folded away, rules containing a literal --&gt; colliding with tombstone escaping unless & was escaped first, and edited rules sinking to the end of the file instead of keeping their slot. Code Tender fixed all three in one commit.
